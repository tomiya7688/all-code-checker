# C# の解析

C# backend は Roslyn と MSBuildWorkspace で実際の project compilation を作成し、compiler 診断と control/data flow の情報を取得します。

## 実行前の準備

all-code-checker の実行には .NET 10 SDK が必要です。解析対象 project の SDK と参照ライブラリも利用できる状態にしてください。project の読み込み時に restore は自動実行しません。

```sh
dotnet restore path/to/App.csproj
dotnet run --project src/AllCodeChecker.Cli/AllCodeChecker.Cli.csproj -- path/to/App.csproj
```

solution を指定する場合も、先に対象 solution を restore します。

```sh
dotnet restore path/to/App.sln
dotnet run --project src/AllCodeChecker.Cli/AllCodeChecker.Cli.csproj -- path/to/App.sln
```

## 入力と解析範囲

- `.csproj`：指定 project の compilation を解析します。参照先 project は型解決に利用し、指定 project の診断に混ぜません。
- `.sln`：対象の C# project を別々の compilation として解析します。同名の型が別 project に存在しても、同じ compilation に統合しません。
- ディレクトリ：探索で検出した project 境界ごとに解析します。同じフォルダーに複数の `.csproj` がある場合も、それぞれ読み込みます。
- `.cs`：近くの project 定義を利用し、指定ファイルに診断と flow summary を絞ります。ファイルが MSBuild の Compile item に含まれなければ partial として報告します。
- project 定義がない `.cs`：プラットフォーム参照を使って解析します。トップレベル文も扱いますが、project 固有の参照・build property は取得できないため、結果は常に partial です。

生成コードも型解決に必要なため compilation に残します。診断と flow summary の出力時に、以下のファイルを除外します。

- `.g.cs`、`.generated.cs`、`.designer.cs`、`AssemblyInfo.cs`
- 先頭 2,048 文字の先頭コメントに `<auto-generated` があるファイル（通常の文字列リテラルやメソッド内コメントは対象外）

## 診断と部分解析失敗

構文エラーは ACI002、代表的な未解決シンボル・型不整合・メンバー参照・呼び出しエラーは ACI003〜ACI006 に変換します。現時点の nullable 警告の変換対象は CS86xx で、ACI008 として出力します。

未分類の compiler error や workspace・semantic・flow の解析失敗は ACI001 で報告します。読み込みや flow 解析の一部が失敗した場合、利用可能な診断と解析情報を残し、orchestrator が ACI903 を追加します。すべての対象を解析できたという意味の Complete と、ソースに問題がないという意味は別です。

ACI903 は「危険」の診断です。`--fail-on` と severity filter による既存の出力・終了コード判定が適用されます。C# 以外の backend が未登録であることも、同じ partial 診断で報告します。

## flow 情報と検証

`AnalyzerScopeResult.AnalysisData` から `CSharpFlowAnalysisSummary` を取得できます。対象はメソッド、accessor、local function、lambda、トップレベル文です。block の successor と、宣言・読み取り・書き込み・capture などの変数集合を保持します。CLI はこの内部情報を出力せず、診断を表示します。

共通 `AnalyzerFixture` を使う回帰テストでは、project/solution 境界、生成コードの型参照、単一ファイルの診断範囲、部分解析失敗、nullable、トップレベル文と入れ子の flow を確認します。

```sh
dotnet test src/AllCodeChecker.Core.Tests/AllCodeChecker.Core.Tests.csproj -c Release
dotnet test src/AllCodeChecker.Cli.Tests/AllCodeChecker.Cli.Tests.csproj -c Release
dotnet run --project src/AllCodeChecker.Cli/AllCodeChecker.Cli.csproj -c Release -- src --fail-on notice
```
